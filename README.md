## 🚀 Featured Project

### 💊 Grand Med — *Never Miss a Tablet Again*

**Grand Med** is an AI-powered medication management project designed to help elderly people take their medicines on time while allowing family members and caregivers to keep track of medication routines.

### ✨ Key Features

- 🤖 **AI Prescription Scanning** — Extracts medicine names, dosages, and timings from prescription images, with caregiver or clinician verification.
- ⏰ **Smart Reminders** — Sends notifications when it is time to take medicines.
- 👨‍👩‍👧 **Caregiver Monitoring** — Allows authorized family members or caregivers to monitor medication confirmations.
- ⌚ **Smartwatch Integration** — Supports vibration alerts and one-tap confirmation on compatible devices.

The project aims to make medication management easier for elderly users while keeping caregivers informed.

> **Vision:** To help every elderly person manage their daily medication schedule with greater confidence, while keeping caregivers informed.
